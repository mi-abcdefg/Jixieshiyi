# CRTC2026 机器人选型和技术路线

## 1. 项目目标与约束

本项目面向重庆大学机器人训练大赛（CRTC2026），围绕资源争夺场景，自主完成机器人机械结构、嵌入式控制、遥控通信和整机集成。当前方案以人工遥控为主，先实现稳定、可复现的基础运动和抓取/收集能力，再根据整机测试结果继续优化。

方案制定以《CRTC2026 参赛手册
V1.0》为依据。提交前仍需核对组委会发布的最新规则版本；若规则更新，以最新版本为准。

### 1.1 关键约束

-   初始长、宽不超过 `260 mm × 190 mm`，初始高度不超过 `200 mm`。
-   可变机构及车体还需满足规则规定的运动包络限制。
-   整机重量不超过 `2.0 kg`。
-   指定使用 18650
    电池；每台机器人仅允许安装一个供电模块，额定电压不超过 `7.4 V`。
-   必须适配官方指定的无线继电器，能够在 `10 m`
    范围内单独遥控切断底盘电源。
-   结构需满足安全要求、线路布置要求及赛前跌落检测要求；规则要求从约
    `150–200 mm` 高度以底面朝下自由下落，无零件掉出。
-   机器人不得使用直接购买的成熟商品机器人或机器人套件参赛，需自行设计、开发和制作。
-   机器人通过 PS2 手柄控制是规则允许且与基础功能考核直接相关的方案。

以上数值摘自参赛手册中的机器人技术规范。尺寸、重量、成本等指标应在最终装配后实测，不应仅依据
CAD 模型认定合规。

## 2. 总体方案

机器人采用"麦克纳姆轮底盘 + 多关节舵机机械臂/夹爪 + STM32 控制板 + PS2
无线手柄"的技术路线。

-   **底盘**：四个麦轮提供平面全向移动能力，包括前后、横移、斜向移动和原地旋转。
-   **操作机构**：四个舵机按底座、肩、肘、夹爪的功能层级组成机械臂。机械臂用于调整抓取姿态并操作场地方块。
-   **收集结构**：底盘前端设置固定式挡板
    B3，利用底盘移动将方块推拢、收集；机械臂夹爪用于更精确的抓取动作。
-   **主控与驱动**：采用 STM32F103 核心板，使用两个 DRV8833
    模块驱动四个底盘直流电机，并通过定时器 PWM 驱动四个舵机。
-   **遥控与安全**：PS2 接收器通过 GPIO
    时序通信；无线继电器承担底盘电源的远程切断功能。软件使能和遥控断电是不同层级的措施，不能相互替代。
-   **软件架构**：采用 FreeRTOS（CMSIS-RTOS
    v1）组织遥控通信、底盘控制、机械臂控制和状态指示等任务。

## 3. 关键技术选型及理由

### 3.1 麦克纳姆轮底盘

选择麦轮的主要考虑是比赛场地中需要快速调整车体位置与朝向。与普通差速底盘相比，麦轮可以通过四轮速度组合实现横移和斜移，减少为对准方块而反复转向的动作。

控制上采用麦轮运动学解算，将手柄左右摇杆输入转换为四轮目标速度，再归一化并映射到
PWM 占空比。底盘实测轴距和轮距均为
`12 cm`，作为当前运动学参数。该参数应在更换底盘或轮组后重新测量。

### 3.2 STM32F103 与 FreeRTOS

STM32F103 用于处理 PS2 通信、底盘运动学、电机 PWM、舵机 PWM
和操作模式管理。FreeRTOS
将周期性任务拆分，便于把遥控采样、底盘闭环/指令输出与机械臂动作编排分离。

当前框架使用约 `10 KB`
的系统堆配置，并增加堆分配失败指示。该值是当前工程的配置，不代表所有后续版本均可直接沿用；新增任务或增大栈空间时应重新核算
RAM 使用情况。

### 3.3 PS2 无线手柄

PS2
手柄是规则推荐且已具备的输入设备，可同时提供按键和模拟摇杆数据。接收任务以约
`10 ms` 周期读取应答并解析按键、模式和摇杆量。

实践中发现仅发送轮询命令不能保证摇杆处于模拟模式，因此软件增加了模拟模式配置和数据有效性检查。对全零或全
`0xFF` 的异常摇杆字节按中位处理，避免通信未就绪时产生满速指令。

### 3.4 DRV8833 与 PWM 电机驱动

两个 DRV8833 模块分别承担四个底盘电机的驱动。控制程序将目标轮速换算为
PWM 占空比，并处理电机方向配置。PWM 频率由早期约 `15 Hz` 调整至
`20 kHz`，以减少低频驱动带来的不良表现；占空比根据定时器运行时 ARR
计算，降低频率调整时的维护成本。

实际接线、电机方向和驱动使能引脚必须以硬件实测为准。开发中发现 PB2
未实际连接到驱动使能脚，后续将软件配置改到
PB10，需确保实物焊接与最终代码一致。

### 3.5 舵机机械臂

机械臂采用三个 SG90 小舵机和一个 MG995
大舵机。当前记录中的安装功能为底座、肩、肘和夹爪四个关节/机构。四路 PWM
使用 TIM4（PB6--PB9），因为 TIM3 的相关资源已被底盘电机使用。

机械臂软件从固定动作逐步扩展为分层控制：舵机驱动层、关节空间控制层、逆运动学/动作序列/摇杆点动层和任务编排层。采用柱坐标逆解进行平面末端点动，并加入关节角增量限幅，以降低机械臂接近伸直或折叠边界时的速度尖峰。

### 3.6 3D 打印结构件

采用 Fusion 360 进行结构建模，使用 3D 打印制作底盘 B1、外壳 B2、挡板 B3
和机械臂连接、伸长、夹爪等部件。选择该路线便于快速迭代、降低复杂零件的加工门槛，并可针对实测干涉和强度问题修改模型后重新打印。

开发过程表明，CAD
尺寸不能直接等同于打印后尺寸。孔位需要考虑打印误差，受力区域需要增加厚度、凸台或加强筋，并为走线和装配工具留出空间。最终结构需通过实物装配、运动干涉检查及跌落测试验证。

## 4. 软件架构与数据流

### 4.1 任务划分

-   `RemoteCommTask`：周期性读取 PS2 手柄，解析按键和摇杆。
-   `ChasisControlTask`：根据操作模式和摇杆指令进行麦轮解算，输出四轮
    PWM。
-   `ArmTask`：以约 `20 ms` 周期编排机械臂动作、逆解和摇杆点动。
-   状态指示任务：显示 PS2 链路状态等信息。
-   舵机通道辨识测试任务：用于台架检查，正常运行时不启动。

各任务通过统一的任务基类封装创建过程。底盘/机械臂操作模式由独立模块管理；当前设计为底盘任务写入模式状态，其他任务只读，以减少多个任务同时修改共享状态的风险。

### 4.2 控制链路

**底盘链路：**

`PS2 摇杆 → 摇杆有效性/模式判断 → 麦轮运动学解算 → 轮速归一化 → PWM 占空比换算 → DRV8833 → 四个直流电机`

**机械臂链路：**

`PS2 按键/摇杆 → 操作对象模式判断 → 预置动作或末端点动 → 逆运动学/关节限速 → 舵机角度指令 → TIM4 PWM → 舵机`

**安全链路：**

`无线继电器遥控器 → 底盘供电切断`

软件中的 L2
电机使能、模式切换和无线继电器分别承担不同功能。整机验收时应单独验证无线断电功能，不应把软件停机等同于物理断电。

## 6. 开发与验证路线

1.  **规则拆解与方案确定**：整理尺寸、重量、电源、安全、无线断电、底盘运动、舵机运动、方块携带和结构稳定性要求。
2.  **机械建模与物料准备**：确定底盘布局、主板/电池/接收器安装位置，设计机械臂和挡板，预留线束、紧固件和运动空间。
3.  **底层驱动验证**：单独验证 PS2 通信、单电机驱动、PWM
    输出、舵机通道和无线继电器。
4.  **功能模块开发**：实现麦轮解算、速度映射、操作模式管理、机械臂固定动作和末端点动。
5.  **软件集成**：在 FreeRTOS
    下集成通信、底盘、机械臂和状态指示任务，检查任务创建结果和共享状态。
6.  **整机装配与调试**：检查孔位、紧固件、线束、机械干涉、电机方向、舵机方向和底盘振动。
7.  **规则验证**：实测初始尺寸、重量、断电范围；验证底盘水平运动、舵机动作、方块携带、结构稳定性和跌落检测。
8.  **留档与交付**：保留代码版本、测试视频、实测数据和问题闭环记录；文档按开发时间组织并存放在仓库根目录的
    `docs/` 文件夹。

## 7. 当前状态与待完成验证

根据现有开发记录，底盘控制逻辑已进行代码测试、修复与优化；PS2
按键和摇杆通信已打通；整车工程已合并机械臂控制模块；机械臂逆解、限速与方向标定已完成阶段性修正；机械结构已进入整机装配和实物调整阶段。

但现有记录并未提供所有比赛指标的最终验收证据，因此本文不将以下项目标记为已通过：

-   最终整机尺寸、重量及成本核验；
-   无线继电器在 10 m 范围内切断底盘电源的验收；
-   180 mm 左右跌落测试及无零件脱落的验收；
-   所有基础功能考核的视频证据；
-   四套预置动作的最终实物角度标定；
-   多次连续抓取、携带和收集测试的成功率统计。

这些项目应在整机稳定后逐项测试，并将数据、照片或视频链接补充到仓库文档中。
